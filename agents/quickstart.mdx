seenpaid is built to be driven by an AI agent. In five minutes you'll go from nothing to your agent scheduling a real post and answering a real question about your account — no dashboard required. Here's the whole path.

<Info>
  You'll need a seenpaid account with at least one connected channel. New here? Run the [getting-started journey](/start/create-your-account) first, then come back. Revenue questions additionally need [attribution](/guides/turn-on-revenue-attribution) switched on and a revenue source connected.
</Info>

## Step 1 — Create an API key

<Steps>
  <Step title="Open the API settings">
    Go to **Settings → AI agents & API** in the dashboard.
  </Step>
  <Step title="Create a key">
    Click **Create API key**, name it (e.g. `claude-agent`), and copy the secret. It starts with `sp_` and is shown **once** — store it safely. If you lose it, revoke it and make a new one.
  </Step>
</Steps>

The key is scoped to one workspace. An agent using it can act on that workspace's data and nothing else. Full detail: [API keys](/agents/api-keys).

## Step 2 — Connect your agent over MCP

Point your MCP client at seenpaid's endpoint with the key as a Bearer token.

<Tabs>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http seenpaid https://api.seenpaid.com/mcp \
      --header "Authorization: Bearer sp_YOUR_KEY"
    ```
  </Tab>
  <Tab title="Claude Desktop / Cursor (JSON)">
    ```json
    {
      "mcpServers": {
        "seenpaid": {
          "type": "http",
          "url": "https://api.seenpaid.com/mcp",
          "headers": {
            "Authorization": "Bearer sp_YOUR_KEY"
          }
        }
      }
    }
    ```
    Put this in `claude_desktop_config.json` (Claude Desktop) or `~/.cursor/mcp.json` (Cursor), then restart the app.
  </Tab>
</Tabs>

<Check>
  "Connected" means your client lists seenpaid's tools. In Claude Code, run `/mcp` to confirm. You should see tools like `schedule_post`, `validate_post` and `list_accounts`.
</Check>

## Step 3 — Schedule something real

Now just talk to your agent in plain language. Try:

> "Which accounts do I have connected? Then schedule 'Testing my new setup — hello from seenpaid' to the first one for tomorrow at 9am."

The agent calls `list_accounts`, then `schedule_post`, and tells you what it queued. No tool names, no dashboard. Check **Calendar** in the dashboard if you like; the post is there.

Then push it further:

> "Will this caption post cleanly to X, LinkedIn and Instagram? And how did last week's posts do?"

That's `validate_post` and a read of your engagement, driven from one sentence. With [revenue attribution](/guides/turn-on-revenue-attribution) on, *"Which of my posts made the most money this month?"* works the same way through `get_top_posts`.

## What just happened

You gave an agent a scoped key, connected it to seenpaid's 50 tools over MCP, and it read your account and scheduled a post — the same org-scoped services the dashboard uses. From here the agent can run the whole loop: plan, validate, publish, read the results, and double down.
