seenpaid is **agent-native**. Any AI agent that speaks [MCP](https://modelcontextprotocol.io) — Claude, ChatGPT, Hermes, Cursor, or your own — can schedule and publish posts, check your channels and read results directly, using the same org-scoped services as the dashboard.

<Note>
  The pitch in one line: **your AI agent runs your socials.** With [revenue attribution](/guides/turn-on-revenue-attribution) switched on, it can also read which posts made money.
</Note>

<Info>
  Just want to wire it up? Skip to [MCP server](/agents/mcp) for the endpoint and config, or [API keys](/agents/api-keys) to get a token first.
</Info>

## What an agent can do

seenpaid exposes **50 MCP tools** in six groups. An agent can run the whole loop — plan, validate, publish, read the results, and double down — without a human opening a dashboard.

<CardGroup cols={2}>
  <Card title="Publishing & posts" icon="paper-plane">
    Draft, validate against each platform's rules, schedule, bulk-plan a week, edit, cancel, repost.
  </Card>
  <Card title="Media" icon="image">
    Generate an image, render carousel slides, pull a file from a URL or upload your own, reuse the library.
  </Card>
  <Card title="Workspace & channels" icon="gear">
    Accounts, health, plan limits, notifications, per-platform requirements, and connect links.
  </Card>
  <Card title="Automation" icon="robot">
    Autopilot drafts you approve, caption A/B experiments, and auto-recycle of proven posts.
  </Card>
  <Card title="Money & attribution (optional)" icon="chart-line">
    With attribution on: per-post revenue, top earners, dead posts, channel ROI, and the honest match rate.
  </Card>
  <Card title="Insight & timing (optional)" icon="lightbulb">
    With attribution on: the patterns behind earning posts, a per-draft forecast, and when to post next.
  </Card>
</CardGroup>

<Note>
  The money and insight tools need [revenue attribution](/guides/turn-on-revenue-attribution) switched on for the workspace. With it off (the default) they reply *"Revenue attribution is off for this workspace — turn it on in Settings"* instead of returning zeros. Scheduling, media, workspace and automation tools work either way.
</Note>

## How it's scoped

Every agent request authenticates with a **seenpaid API key**, which maps to exactly one organization. An agent can only ever see and act on its own account's data — the MCP server is built fresh per request and bound to that org. No cross-account access, ever.

## Get connected in two steps

<Steps>
  <Step title="Create an API key" icon="key">
    Generate a key in the dashboard. See [API keys](/agents/api-keys).

  <Step title="Add the MCP server" icon="plug">

  </Step>
</Steps>
