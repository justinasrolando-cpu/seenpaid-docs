seenpaid is **agent-native**. Any AI agent that speaks [MCP](https://modelcontextprotocol.io) — Claude, ChatGPT, Hermes, Cursor, or your own — can publish posts and read revenue directly, using the same org-scoped services as the dashboard.

<Note>
  The pitch in one line: **your AI agent posts, seenpaid tells you which posts made the money.**
</Note>

<Info>
  Just want to wire it up? Skip to [MCP server](/agents/mcp) for the endpoint and config, or [API keys](/agents/api-keys) to get a token first.
</Info>

## What an agent can do

seenpaid exposes **47 MCP tools** in six groups. An agent can run the whole loop — publish, measure what paid, and double down — without a human opening a dashboard.

<CardGroup cols={2}>
  <Card title="Money & attribution" icon="chart-line">

  </Card>
  <Card title="Insight & timing" icon="lightbulb">
    The patterns behind earning posts, a per-account forecast, and when to post next.
  </Card>
  <Card title="Publishing & posts" icon="paper-plane">
    Draft, validate, schedule, edit, and repost — tracked links included automatically.
  </Card>
  <Card title="Media" icon="image">

  </Card>
  <Card title="Automation" icon="robot">
    Autopilot drafts, revenue-decided A/B experiments, and auto-recycle of proven winners.
  </Card>
  <Card title="Workspace & channels" icon="gear">
    Accounts, health, plan limits, notifications, and connect links.
  </Card>
</CardGroup>

<Note>
  What no other scheduler's tools can do: every publish tool is paired with a **money** tool. The agent doesn't just post — it can read which post earned, forecast a draft before it schedules it, and stop making the content that gets clicks but no sales.
</Note>

## How it's scoped

Every agent request authenticates with a **seenpaid API key**, which maps to exactly one organization. An agent can only ever see and act on its own account's data — the MCP server is built fresh per request and bound to that org. No cross-account access, ever.

## Get connected in two steps

<Steps>
  <Step title="Create an API key" icon="key">
