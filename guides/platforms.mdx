seenpaid publishes to a wide set of networks — mainstream social, the fediverse, developer blogs, and raw webhooks. This is the reference to check **before** you write one caption for several platforms: the limits below are the exact values the publisher enforces, not estimates.

<Info>
  Building with an AI agent? It can read all of this at runtime with [`get_platform_requirements`](/agents/tools-reference#get_platform_requirements), and dry-run a real caption against specific platforms with [`validate_post`](/agents/tools-reference#validate_post) — before a single publish attempt is spent.
</Info>

## The three ways a platform connects

You never register seenpaid anywhere. What differs per network is **where the permission comes from** — and that's set by the platform, not by us.

<CardGroup cols={3}>
  <Card title="Click &amp; authorize (OAuth)" icon="arrow-up-right-from-square">
    Click **Connect**, sign in on the platform's own site, approve. Nothing to copy or paste. **LinkedIn, Mastodon, Pinterest, Tumblr.**
  </Card>
  <Card title="Paste your own key (BYOK)" icon="key">
    The network hands *you* a credential — an app password, API key, bot token, or webhook URL — and you paste it in once. Nothing for us to register. **Bluesky, Discord, Telegram, Slack, WordPress, Ghost, Dev.to, Hashnode, Medium, Lemmy, Nostr, Webhook.**
  </Card>
  <Card title="Not yet available" icon="clock">
    **Facebook, Instagram, Threads, TikTok** publish through APIs that require platform review (in progress). **X** connects via your own keys but needs your own paid API credits. **Reddit, VK** are coming soon.
  </Card>
</CardGroup>

<Note>
  The dashboard always shows the truth for your account: open **Channels** and each platform shows exactly how it connects (or that it's coming soon). We'd rather grey a button out than hand you one that quietly fails. See [Connect your channels](/guides/connect-channels) for the click-by-click walkthrough.
</Note>

<Info>
  **"Link in post" vs "Bio link."** On most platforms seenpaid rewrites a URL in your caption to a tracked short link automatically. **Instagram and TikTok don't make caption links clickable**, so a tracked URL there would just be dead text — seenpaid routes those through your [bio page](/guides/bio-page) instead. An agent can mint one explicitly with [`create_tracked_link`](/agents/tools-reference#create_tracked_link).
</Info>

## Platform-specific catches

A few behave in a way worth knowing **before** you publish, not after.

<AccordionGroup>
  <Accordion title="X — API posting is paid (X's pricing, not ours)" icon="x-twitter">
    X charges for API posting on your own developer account. You connect X by pasting your own API keys, and you need credits (or the free-tier voucher) on your X developer account or a publish attempt fails on X's side. Every free platform — Bluesky, LinkedIn, Mastodon, and the rest — posts at no cost.
  </Accordion>
  <Accordion title="TikTok — lands as a draft you finish by hand" icon="tiktok">
    TikTok's API forbids apps from publishing directly. seenpaid delivers your post to your TikTok inbox as a **draft**; you open TikTok and tap **Post** yourself. It requires a **video** (not an image), 64MB or under. (Connecting TikTok is pending platform review.)
  </Accordion>
  <Accordion title="Instagram &amp; Pinterest — media is mandatory" icon="image">
    Instagram's API rejects text-only posts — attach at least one image or video. Pinterest can't create a Pin without an image. seenpaid warns you in the composer before you publish, not after.
  </Accordion>
  <Accordion title="Meta (Facebook, Instagram, Threads) — pending app review" icon="clock">
    These publish through Meta's Graph API, which gates publishing behind Meta's app review. They're fully wired and light up the moment review clears. Until then, start with any Live channel above.
  </Accordion>
  <Accordion title="Bluesky — connect with an app password, not your login" icon="cloud">
    Create an **app password** in Bluesky (Settings → App Passwords) and paste that — never your main password. It's revocable independently, so you stay in control.
  </Accordion>
</AccordionGroup>

<Tip>
  Publishing the same caption everywhere? **X's 280 characters** is almost always the binding limit. Use `per_account_captions` on [`schedule_post`](/agents/tools-reference#schedule_post) (or the per-platform editor in the composer) to send a short version to X and the full text everywhere else.
</Tip>
